CHAPTER 03 / THE ENGINE ROOM

The Four Steps of Optimization

Stripped of mystical jargon, machine learning is high-speed guesswork refined by calculus. All modern systems repeat this precise 4-step loop millions of times.

PHASE 01

1. Make a Guess

The model starts with random weights (knob settings). Given an input (e.g. house square footage), it spits out an initial blind prediction.

PHASE 02

2. Measure the Error

Known formally as the Loss Function. It subtracts the guess from reality and squares the difference. A bad guess produces a huge error score.

PHASE 03

3. Calculate Direction

Using calculus (gradient descent), the computer determines whether nudging weight knob #1 up or down will decrease the loss score.

PHASE 04

4. Nudge & Repeat

The weights are nudged by a tiny increment. The machine ingests the next batch of data and repeats until the error stops dropping.
